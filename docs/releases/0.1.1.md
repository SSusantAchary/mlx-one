# MLX-One 0.1.1 — approved for release

**Maintainer approval: 8 November 2026. Published on PyPI; verified 10 November 2026.**

MLX-One 0.1.1 brings **40 supported native model types across seven modalities**.
Every type has a passing primary-workflow record for an exact checkpoint revision,
precision and operation. Model tests, relevant public interfaces, native Metal
regressions and clean package checks back this release decision.

The published installation is `mlx-one==0.1.1`.
[PyPI files](https://pypi.org/project/mlx-one/0.1.1/#files) and the
[publication verification](0.1.1.json) identify the uploaded artifacts.
See [0.1.2 release notes](0.1.2.md) for the subsequent model additions.

[Local PyPI artifacts and upload steps](0.1.1-pypi.md) describe the prepared
package, metadata validation and maintainer-run publication.

## Changes in this release

- Corrected OpenELM/LFM2 prompt and BOS handling, Qwen MoE quantized loading,
  retrieval tokenizer/weight mapping and model leases in serving.
- Matched the published ColBERT projection/query expansion behavior and added
  an explicit FP32 execution profile for BF16-stored Qwen3 Embedding weights.
- Verified forced alignment on independently timed TIMIT samples, and checked
  NER tokenization, logits and aggregation against the publisher implementation.
- Repaired OCR visible-text handling, byte decoding and publisher decoding
  constraints; added native beam decoding for Florence.
- Repaired LFM speech EOS/state ordering and request-local sampling; selected
  the tested 8-bit checkpoint for ASR, TTS and speech-to-speech.
- Added standalone SAM3 temporal tracking and corrected reference-compatible
  image resizing, per-object outputs and temporal session behavior.

## Validation

**2,573 tests passed, 9 subtests passed, 95 optional tests skipped** on Apple M4,
32 GiB, MLX/Metal 0.32.2. Skipped tests are reported separately from passes.
The exact wheel/sdist payload and isolated installed-wheel checks pass. Native
inference runs without Torch, Transformers or the upstream MLX model libraries.

Real-checkpoint records retain their actual candidate-wheel identities. The final
package was audited separately; it adds the support catalog and help-text updates
to the final inference build. Campaign-downloaded checkpoint weights were removed
after outputs were saved. The user's protected GPT-OSS assets were preserved.

## Quality and scope limitations

Support follows MLX-LM-style model admission: implementation tests, real
checkpoint task output and working relevant interfaces. It does not require a
blanket experimental label or a universal benchmark score.

- **Florence:** the latest recorded page CER is **32.87%**, above the original
  25% diagnostic floor. The independent publisher run also exceeded that floor.
  Plain OCR is supported; the failed optional region-parser workflow is excluded.
  Older corpus measurements retain their own datasets and token limits.
- **Alignment:** the current TIMIT checks pass with **29.472 ms mean** and
  **68.1875 ms p95** boundary error. The historical 800-ms discrepancy is preserved
  in the old reports and is superseded for this tested profile.
- **LFM speech:** support selects the tested **Q8** checkpoint. Weaker Q4 speech
  accuracy measurements do not become Q8 accuracy evidence.
- **NER:** F1 **0.6024** on the small diagnostic sample matches the publisher
  implementation; the sample is separate from a broad quality benchmark.
- **SAM video:** native offline/streaming and CLI workflows pass; an optional
  MPS reference streaming discrepancy remains documented.
- Other checkpoint sizes, precisions, long contexts, languages, task extensions
  and hardware need evidence appropriate to any additional claim. MLXBoost,
  training and other optional experiments retain their separate status.
