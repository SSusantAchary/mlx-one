MLX-One 0.1.4 improves local chat and GPT-OSS serving while retaining the existing
45-model-type, seven-modality support catalog.

### Changes

- Redesigned chat workspace with tabs, session history/search, message actions,
  model badges, timing snapshots and context/cache usage.
- Reasoning-aware GPT-OSS streaming with live progress, output-limit notices,
  retry with more tokens and preserved partial answers on interruption.
- Context-bounded 8192-token/low-effort GPT-OSS UI recommendation, respecting
  explicit limits; buffered rendering with a final flush.
- Colored elapsed server logs with slot/task IDs, live decode rate, separate
  model/visible TTFT and final memory/cache summaries.
- Native sampling and eligible GPT-OSS attention/host-overhead optimizations,
  preserving reference fallback and memory protections.
- Refreshed logo, architecture artwork, README, GitHub Pages and PyPI description.

### Performance scope

Bounded M4 measurements improved; a fixed 1024-token request measured
19.38 → 28.91 decode tok/s with matching visible response hashes. Longer
2016-token responses measured 21.11 tok/s without browser rendering and
15.39 tok/s in the UI. Sustained throughput remains variable; this release does
not claim sustained 30+ tok/s or full 128K HTTP/tool qualification.

### Install after PyPI publication

```bash
python -m pip install --upgrade "mlx-one[server]==0.1.4"
mlx-one --version
```
