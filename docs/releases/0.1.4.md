# MLX-One 0.1.4

**Published on PyPI on 15 November 2026; uploaded SHA-256 values match the
validated artifacts. The GitHub release is pending.**

This maintenance release improves local chat, GPT-OSS streaming, serving logs
and bounded execution overhead. It retains the reviewed catalog of **45 native
model types, seven modalities and 50 checkpoint profiles**. It adds no new model
admissions and does not relabel historical model results as new release tests.

[Preparation record](0.1.4.json) · [Git and PyPI handoff](0.1.4-pypi.md).

## Changes

- Redesign the bundled chat workspace with a sidebar, session tabs/history and
  search; add message edit, copy, retry, regenerate, branch and delete controls.
  Show model badges, per-turn timing and context/cache usage. Chats and API keys
  remain session-only; MCP management is explicitly unavailable.
- Parse ordinary GPT-OSS chat with the token-aware Harmony parser. Count hidden
  reasoning without sending its text to the UI; emit progress while reasoning,
  explain output-limit stops and preserve interrupted partial answers.
- Recommend up to **8192 output tokens and low reasoning effort** for GPT-OSS
  UI sessions when context allows. Preserve explicit user limits. Coalesce text
  rendering over 80 ms and flush pending output at completion or interruption.
- Preserve scheduler forward-request responses through the logging wrapper,
  including batched HTTP requests and principal-isolated prefix reuse.
- Add elapsed terminal logs, slot/task IDs, periodic decode progress, separate
  model/visible-text TTFT and final cache/context/memory summaries. Expose
  `--log-level` and `--log-progress-interval`, respecting `NO_COLOR`.
- Vectorize sampled token selection while retaining Python RNG, stable ranking,
  top-k/top-p and normalization semantics. Keep greedy selection unchanged.
- Skip activation-calibration identity work when no calibration candidate exists;
  retain live candidate validation, memory forecasts and admission guards.
- Omit redundant full-history single-query attention masks only for the eligible
  opt-in GPT-OSS recipe. Keep sliding attention and unsupported layouts on the
  reference path. A sliding-window candidate that changed the response was rejected.
- Refresh the three-bar logo and architecture image, placing Architecture after
  Why MLX-One in the README and documentation homepage. Update PyPI descriptions
  and GitHub Pages navigation from their maintained sources.

## Performance evidence and limits

Apple M4 / 32 GiB, MLX 0.32.2. These are different bounded workloads and are not
interchangeable benchmark cohorts:

| Workload | Observed decode throughput |
| --- | ---: |
| Sampled short-request median, original to vectorized sampler | 12.90 → 32.19 tok/s |
| Fixed 1024-output-token API request, before/after attention change | 19.38 → 28.91 tok/s |
| Subsequent 2016-token browser-free response | 21.11 tok/s |
| Subsequent 2016-token live UI response | 15.39 tok/s |

The fixed 1024-token request retained its visible response hash. It is one
sequential observation, not exhaustive token parity or a controlled thermal
crossover. **Sustained long-response speed remains unresolved.** No sustained
30+ tok/s, universal llama.cpp parity, full-context memory fit or full 128K
HTTP/tool qualification is claimed. Increasing the output budget raises a ceiling;
it does not require the model to generate that many tokens.

## Validation scope

Focused backend, UI and browser regressions cover the changed paths. Earlier
Metal attention tests and actual-model requests are retained with their original
hardware and workload identities. Model equations and support catalogs outside
the documented GPT-OSS execution change are preserved; the historical 45-model
campaign was not rerun for this maintenance release.

The local artifact checks are recorded in [the release validation record](0.1.4-validation.json).

## Installation

After the branch is pushed, install its exact Git revision for testing:

```bash
python -m pip install --upgrade --force-reinstall \
  "mlx-one[server] @ git+https://github.com/SSusantAchary/mlx-one.git@release/v0.1.4"
```

Install the published PyPI release:

```bash
python -m pip install --upgrade "mlx-one[server]==0.1.4"
mlx-one --version
```

MLXBoost remains optional and profile-specific. See the
[GPT-OSS serving guide](../mlxboost/gptoss-serving.md) and
[UI/server guide](../ui.md) for configuration and API-key setup.
