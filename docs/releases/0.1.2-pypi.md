## Install

```bash
python -m pip install --upgrade "mlx-one==0.1.2"
mlx-one --version
```

The GitHub release uses tag `0.1.2` and the
[prepared release notes](0.1.2-github.md). Its tag must contain the validated
production source; push the release commits before creating it. Merge the
documentation changes into `main` to deploy the updated GitHub Pages site.
