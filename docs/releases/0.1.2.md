# MLX-One 0.1.2

**Approved for publication on 10 November 2026.** This release adds ten verified
checkpoint workflows and five architecture types, bringing the library to
**45 native model types across seven modalities**, represented by **50 verified
checkpoint profiles**. Publication state is recorded separately in the
[release decision](0.1.2.json).

## Install

```bash
python -m pip install --upgrade "mlx-one==0.1.2"
python -m pip install --upgrade "mlx-one[server,vision,kokoro]==0.1.2"
```

[PyPI release and files](https://pypi.org/project/mlx-one/0.1.2/) ·
[Artifact checks and upload instructions](0.1.2-pypi.md).

## New native workflows

- **T5-small:** encoder-decoder text-to-text generation with bounded greedy decoding.
- **ViT-base:** supervised 224×224 RGB image classification with trained ImageNet labels.
- **Kokoro-82M:** native 24 kHz English speech using the `af_heart` voice.
- **BGE-M3:** dense, learned sparse and ColBERT representations, plus hybrid scoring.
- **Nomic Embed v1.5:** normalized full vectors and explicit Matryoshka dimensions.
- **BERT/XLM-R retrieval:** BGE-small, multilingual MiniLM, multilingual E5,
  MiniLM cross-encoder and BGE Reranker profiles.

Applicable Python, CLI, Engine and HTTP workflows were exercised with actual
checkpoint weights from an isolated installed wheel. BGE-M3's extra sparse/token
representations use Python/CLI; dense vectors also have Engine/HTTP coverage.

The README and documentation site now include current modality counts, all
verified checkpoint profiles, workflow examples, source provenance and limits.

## Validation and scope

The implementation records **2,599 passing native tests, 9 passing subtests and
95 skips**, followed by **54 passing targeted checks**. Core regression checks
passed on Python 3.10–3.13; native checkpoint execution used Python 3.12 on
Apple M4 / 32 GiB with MLX/Metal 0.32.2. Version 0.1.2 artifacts receive their
own metadata, payload and installed-wheel checks before upload.

- ViT class logits and top-five predictions pass. Its stricter fixed hidden-state
  diagnostic remains failed, with a separately recorded functional decision.
- Kokoro is bounded to `af_heart` English, 510 phonemes and 30 seconds, with no
  streaming claim. Kokoro and BGE-M3 require the documented safe offline conversion.
- Retrieval reference/performance workloads reach 512 tokens; multilingual
  MiniLM has a 128-token limit. Longer contexts and additional quantizations
  are outside the recorded qualification.
- Original accuracy diagnostics, historical benchmarks and optional experimental
  capabilities keep their recorded status. Downloaded qualification weights were
  removed after their results were saved.
