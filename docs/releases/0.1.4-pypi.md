# MLX-One 0.1.4 — publication and Git follow-up

**Published on PyPI on 15 November 2026.** Both uploaded distribution SHA-256
values match the validated artifacts. See the [publication record](0.1.4.json)
and [original validation record](0.1.4-validation.json).

The Git tag is **v0.1.4**, pointing at the tested release commit. Its files and

time of verification; [prepared GitHub release notes](0.1.4-github.md) remain

## Push the branding follow-up

The current checkout is `mlx-one-release-014`, branch `release/v0.1.4`. It adds
black-and-orange branding after the published release. Review and commit any
remaining changes, then push the existing branch:

```bash
git status --short
git add -A
git commit -m "Refresh orange MLX-One branding and verify PyPI publication"
git push origin release/v0.1.4
```

If the follow-up is already committed, run only the push command. Open or update
the pull request into `main`, review hosted checks, then merge it. GitHub Pages
deploys through **Documentation site** on `main`; a branch push alone does not
publish the production site. Settings → Pages must use **GitHub Actions**.

Do not move or recreate `v0.1.4`. A GitHub release may use that existing tag and
its original distribution files. The branding change does not replace the
published wheel or source archive; a future package version is needed for the
new bundled UI icon on PyPI.

## Verify the preserved artifacts

The original files remain under `dist/pypi-0.1.4/` locally. From the repository
root, verify their identities with:

```bash
shasum -a 256 -c dist/pypi-0.1.4/SHA256SUMS
```

Do not rebuild or upload another distribution with version 0.1.4. The
[publication record](0.1.4.json) includes the remote URLs and verified hashes.

## Install

Install the published runtime in the intended environment:

```bash
unset PYTHONPATH
python -m pip install --upgrade "mlx-one[server]==0.1.4"
python -m pip check
mlx-one --version
```

To use the post-release branding after its Git branch is pushed:

```bash
python -m pip install --upgrade --force-reinstall \
  "mlx-one[server] @ git+https://github.com/SSusantAchary/mlx-one.git@release/v0.1.4"
```

After merge, `mlx-one upgrade` installs Git `main` in the CLI's environment,
including updates with the same version number. No PyPI artifact is changed by
that command. Keep local credentials outside source files and chat.
