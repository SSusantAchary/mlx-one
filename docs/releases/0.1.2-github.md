MLX-One 0.1.2 is available on PyPI, with **45 native model types across seven
modalities** and **50 verified checkpoint profiles** on Apple Silicon. This
release adds ten checkpoint workflows and five architecture types.

## Model coverage

| Modality | Native model types |
| --- | ---: |
| Text generation | 12 |
| Vision-language | 4 |
| Audio & speech | 8 |
| OCR & documents | 6 |
| Embeddings & reranking | 7 |
| Segmentation | 4 |
| Classification | 4 |
| **Total** | **45** |

Checkpoint sizes, revisions and quantizations share an architecture type.

## New workflows

- **T5-small:** native encoder-decoder text-to-text generation with bounded greedy decoding.
- **ViT-base:** supervised 224×224 RGB image classification with trained ImageNet labels.
- **Kokoro-82M:** native 24 kHz English speech with the `af_heart` voice.
- **BGE-M3:** dense vectors, learned sparse weights, ColBERT token vectors and hybrid scoring.
- **Dense retrieval:** BGE-small, multilingual MiniLM, multilingual E5 and Nomic Embed v1.5, with checkpoint-specific pooling, prefixes and Matryoshka dimensions.
- **Paired reranking:** MiniLM cross-encoder and BGE Reranker v2 M3.
- **Documentation:** current modality counts, searchable checkpoint profiles, workflow examples and evidence links.

Applicable Python, CLI, Engine and HTTP paths were tested with real checkpoint
weights. BGE-M3's extra sparse/token representations use Python/CLI; dense vectors
also have Engine/HTTP coverage.

## Install or upgrade

```bash
python -m pip install --upgrade "mlx-one==0.1.2"
python -m pip install --upgrade "mlx-one[server,vision,kokoro]==0.1.2"
```

Model weights are acquired separately under the publishers' terms. Kokoro and
BGE-M3 use the documented safe offline conversion.

## Supported scope

Support applies to the recorded checkpoint revisions, precision, task, interfaces
and input limits. ViT classification passes; its stricter hidden-state diagnostic
remains failed and documented. Kokoro is bounded to `af_heart` English, 510
phonemes and 30 seconds, without streaming. Retrieval measurements reach 512
tokens; multilingual MiniLM has a 128-token limit. Optional acceleration and
other experimental capabilities retain their separate status.
