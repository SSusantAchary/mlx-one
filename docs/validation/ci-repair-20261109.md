## Findings

The [observed run](https://github.com/SSusantAchary/mlx-one/actions/runs/42551029446) failed in pytest on Python 3.12 with exit code 2. The other Python jobs were cancelled by matrix fail-fast, while the clean-wheel job passed. Annotations do not include the Python exception; GitHub requires administrator authentication to download that log. The local issues below were reproduced independently.

- A fresh `.[dev]` installation lacked `setuptools`, breaking two packaging-contract tests. It is now an explicit development dependency.
- Python 3.10 could not import the core package because `datetime.UTC` was introduced in 3.11. Timestamp helpers now use equivalent `timezone.utc`.
- Python 3.10 does not have `hashlib.file_digest`; streaming SHA-256 preserves integrity checks in loaders and qualification cleanup. Tests cover binary and multi-chunk files.
- Release TOML audits now fall back to the declared `tomli` development dependency on Python 3.10.

## Workflow changes

Each matrix job creates a venv and invokes `python -m pytest`. Interpreter/dependency diagnostics and a JUnit artifact make future failures inspectable. `fail-fast: false` allows each version to finish. Checkout, setup-python and artifact upload use verified Node.js 24 releases.
